## About UnoForge

UnoForge is a collective of open-source projects aimed at simplifying and beautifying the web development process. We provide a range of tools, from UI component libraries to presets and command-line interfaces, all designed to be intuitive and powerful. Our focus is on the UnoCSS and Tailwind CSS ecosystems, delivering high-quality, customizable solutions for developers.

## Core Projects

Our core projects represent the heart of UnoForge, providing the foundational tools for building modern web interfaces.

### [Unify UI](https://github.com/unoforge/uno-ui)

**Unify UI** is a comprehensive UI component library that allows you to rapidly build websites with a modern look and feel. Powered by UnoCSS, it offers a wide range of customizable components to accelerate your development workflow.

- **Repository**: [unoforge/uno-ui](https://github.com/unoforge/uno-ui)
- **Key Features**:
  - Extensive set of UI components
  - Highly customizable and themeable
  - Built for speed and ease of use

### [Flexilla](https://github.com/unoforge/flexilla)

**Flexilla** is an interactive component library that brings your web applications to life. With a focus on interactivity and user experience, Flexilla provides the tools you need to create dynamic and engaging interfaces.

- **Repository**: [unoforge/flexilla](https://github.com/unoforge/flexilla)
- **Key Features**:
  - Interactive UI components
  - Easy to integrate and use
  - Lightweight and performant

### [Unify Preset](https://github.com/unoforge/unify-preset)

The **Unify Preset** is a powerful UI preset for building custom web UIs. Powered by UnoCSS, it gives you the building blocks to create your own unique designs while maintaining a consistent and professional look.

- **Repository**: [unoforge/unify-preset](https://github.com/unoforge/unify-preset)
- **Key Features**:
  - A solid foundation for custom UI development
  - Fully compatible with UnoCSS
  - Flexible and easy to extend

## Ecosystem

Beyond our core projects, we offer a growing ecosystem of tools to support your development needs.

- **[Laravel UI](https://github.com/unoforge/laravel-ui)**: Beautifully crafted, accessible UI components for Laravel, built with Tailwind CSS v4.
- **[CLI](https://github.com/unoforge/cli)**: A command-line interface to streamline your workflow.
- **[Flexi CLI](https://github.com/unoforge/flexi-cli)**: A shadcn-cli-like tool for PHP developers.
- **[Alpine Plugin](https://github.com/unoforge/alpine-plugin)**: An Alpine.js plugin to enhance your projects.
